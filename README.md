## 🚀 Projects & Implementations
*Code, notebooks, and full implementations for various research topics.*

- 🧠 **[Attention is all you need](./Attention%20is%20all%20you%20need)**: Deep dive into Transformer architecture with positional encoding implementation.
- 🛠️ **[GSOC_tasks](./GSOC_tasks)**: Collection of tasks for GSoC, including Graph Neural Networks (GNN) and Variational Autoencoders (VAE).
- 📉 **[LoRA](./LoRA)**: Implementation and experimentation with Low-Rank Adaptation for large model fine-tuning.
- 🌐 **[Neural Machine Translation](./Neural%20Machine%20Translation)**: A complete NMT system featuring an interactive app, model training scripts, and detailed notebooks.
- ☕ **[Quantifying Complexity](./Quantifying%20the%20Rise%20and%20Fall%20of%20Complexity%20in%20Closed%20Systems:%20The%20Coffee%20Automaton)**: Analysis of the Coffee Automaton, tracking the rise and fall of complexity in closed systems.
- 🔄 **[RNN_LSTM](./RNN_LSTM)**: Implementations of Vanilla RNNs and LSTMs for sequence modeling and prediction.
- 🖼️ **[simCLR](./simCLR)**: Contrastive learning framework for visual representations, including training loops and model architectures.
